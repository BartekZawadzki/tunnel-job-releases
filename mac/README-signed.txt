BREACHWORKS @VERSION@ FOR macOS
===========================

One app for Intel and Apple Silicon Macs, macOS 12 (Monterey) or later.
This is the same game as Breachworks @VERSION@ for Windows: Mac and Windows
players on @VERSION@ can play together over LAN and online. Everyone in a game
needs @VERSION@.

VR (beta) is Windows only: the Mac version plays flat.

The app is signed with an Apple Developer ID and notarized by Apple, so it
opens like any other app downloaded from the internet. No Terminal, no
"Open Anyway" and no extra steps.

INSTALL
-------
1. Double-click Breachworks-macOS.dmg. A "Breachworks" disk window opens.
2. Drag Breachworks.app onto the Applications shortcut in the same window.
3. Eject the Breachworks disk (the eject button next to it in Finder).
4. Start Breachworks from Launchpad or the Applications folder.
   The first time macOS says that Breachworks was downloaded from the
   internet and that Apple checked it for malicious software: press "Open".
5. When the game asks for access to the local network, allow it
   (needed to find and host LAN games). If the macOS firewall is on,
   let Breachworks accept incoming connections.

Already have an older Breachworks in Applications? Drag the new one over it
and choose "Replace". Your settings and saves stay.

UPDATES
-------
When a new version comes out, the game tells you, and "Open the release page"
opens the download page in your browser. Download the new
Breachworks-macOS.dmg there and drag the app to Applications again ("Replace").

LOGS
----
~/Library/Logs/Breachworks/Breachworks/Player.log
(Finder -> Go menu -> Go to Folder... -> paste the path above)
Your settings and saves: ~/Library/Application Support/Breachworks/Breachworks/

If something does not work, please send Player.log, a screenshot
(Cmd+Shift+3 whole screen, Cmd+Shift+4 a region; they land on the Desktop)
and a short note: Mac model, macOS version, what happened.
